# 动态工作流移植验收合同

将 ZCode `3c5b227649371507ddc4eb46ac5133afe6db1cab` 的 Dynamic Workflow 集成到 Composer Assist，同一 bundle 保留输入预测，增加工作流工具及中文操作界面。

## 用户行为

- 在输入框旁打开工作流管理器，可编写 TypeScript、分析并预览依赖图、控制流和阶段交接图；编译错误展示准确行列，错误脚本不得启动。
- Agent 可以生成待确认流程；首次启动由用户查看脚本和图后点击运行。保存的流程支持项目级和全局级；运行选择明确的项目目录。
- 子 Agent 具有独立会话，同一 actor 跨多次 ask 保留上下文；串行、并行、循环、类型化结果、渐进报告、产物、询问及模型选择沿用上游契约。
- 运行中显示阶段、节点状态、执行事件、结果、报告及产物，支持停止。停止、进程中断后，日志仍可读；恢复使用原脚本和已完成结果，修改续跑使用上游 amend 缓存规则。
- 不能确定是否已产生外部影响的执行不得静默重发；恢复须展示阻断原因并提供明确处理动作。
- 权限、模型可用范围、工作目录和子 Agent 生命周期继承 DSH，工作流不取得额外文件或网络权限。

## 实现边界

- 上游编译、分析、Schema、lowering、引擎和子进程运行器保留来源与许可证，优先原样复用。
- DSH 适配层实现会话、journal、world reads、工具、保存管理和通知；Client 使用宿主 React、插槽、主题与本地化。
- 准备与确认分开。模型工具只准备流程，用户界面执行首次启动；其他界面和工具动作调用同一管理器。
- 运行数据置于用户数据目录，不随源码发布；日志写入必须先于相应工作派发。

## 验收

真实上游编译及引擎检查；并发与 actor 顺序；类型错误修复；停止和跨进程恢复不重跑完成节点；修改续跑缓存；权限/归属拒绝；已保存流程与产物；实际 DSH 子 Agent；实际 GUI 操作和图形渲染；预测自检与发行文件清单。每项记录事实，未跑部分明确列出。
